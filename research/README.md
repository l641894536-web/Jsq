# 研究脚本（交易台结论的出处）

在 Claude 工作区里跑的回测脚本，原样存档，方便复查和重跑。数据来自本仓库 `data` 分支（`market_data.load`），
脚本里的路径按工作区写死：`/home/claude/jsq`（本仓库）、`/home/claude/market-data`（data 分支）、`/home/claude/bt`（运行目录）。

| 脚本 | 做什么 |
|---|---|
| `contract_bt.py` | 合约短线规则模拟器：突破/均线交叉进场，前 L 根高低点止损，A=死拿、E=浮盈1R挪保本等出场，扣0.1%来回成本 |
| `regime.py`, `contract_regime.py` | 美股环境（纳指200日线 × VIX）；AMD/美光/戴尔 + 25只科技股分环境回测 |
| `gold_env.py` | 黄金白银：日线环境变量 + 小时线短线规则分牛熊 |
| `newsyms_bt.py` | 加密7币（比特币200日线）、23只非科技蓝筹（标普200日线） |
| `commod_bt.py` | 铂金、钯金、铜、天然气（Dukascopy 商品CFD，自身200日线） |
| `per_symbol_bt.py` | 没进分组的股票合约逐只用自己的小时线回测（Dukascopy 满3年用它，否则 Yahoo 约两年），写进 contract_stats 的 `sym_<代码>`；`--apply` 直接更新交易台。结论：单只两年样本太少，前一年灵的后一年反而偏差 |
| `dip_manage_bt.py` | 熊市回调企稳做多（AMD/美光/戴尔）到1R以后怎么管：保本 / 提到半份 / 跟踪3天低点 / 先平一半不封顶 |
| `dip_clean_bt.py` | 回调企稳做多统一口径复核（一笔平仓后再找下一笔，熊市×纳指前一天涨跌、牛市×纳指整体回调；`--tech` 跑22只科技股），交易台和每日简报的算法与它一致 |
| `build_contract_stats.py` | 汇总成 gh-pages `env_static.json` 的 `contract_stats`（含前后两段 h1/h2） |
| `feat_bt.py` | 美股：能不能用开单前就知道的条件（波动、涨幅、强弱、自身战绩）挑出适合做突破的股票（结论：不能） |
| `daily_bt.py` | 美股日线突破（20日高低点进场、10日反向离场）对比随便进场，扣资金费（结论：没有普遍优势） |
| `structure_bt.py`, `structure_report.py` | K线结构（摆动高低点）转向：方向、幅度、顺着做到认错位的盈亏，多周期组合 |
| `analog_bt.py` | 历史相似行情（找最像的20段历史看之后怎么走），方向和波动范围检验（结论：没通过） |
| `vol_range_bt.py` | 按最近20天波动估明天/5天的区间和"被碰到概率"，校准表给结论卡用 |
| `ashare_pick_bt.py`, `ashare_pick_report.py` | A股选股：成长、增速变化、行业热度、强弱，按已公告财报每月选，牛熊分开 |
| `exit_bt.py` | 出场方式：固定止盈 vs 分批 vs 跟踪止损，按品种和牛熊分开 |
| `range_bt.py` | 震荡期高抛低吸：先识别震荡再做区间两端，按品种和牛熊分开（结论：没通过） |
| `range_big_bt.py` | 4小时/日线大箱体高抛低吸（含资金费）（结论：没通过） |
| `stopwidth_bt.py` | 止损放宽（ATR、3天低点）对突破单和区间单的影响 |
| `scale_in_bt.py`, `pyramid_bt.py` | 分批抄底（30/30/40）vs 一次性 vs 赚了再加，每次100U×5倍 |
| `bear_strats_bt.py` | 熊市做法：分批补到深处、大跌抢反弹、反弹到20日线做空（结论：都不行） |
| `dip_v2_bt.py` | 抄底改良：跌够N倍日波动后企稳再进 vs 跌够就分批，按品种和牛熊 |
| `ndx_ref_bt.py` | 回调企稳做多按纳指100状态分组（整体回调、纳指前一天涨跌、VIX） |
| `bear.py` | 美股跌破200日线：长熊还是短恐慌，认错线 |
| `build_panel.py`, `sentiment.py`, `test_sent.py`, `build_env.py` | A股情绪温度（11个指标） |
| `ashare_vs_us.py`, `stock_bt.py`, `stock_split.py`, `stock_signals.py`, `trendstart.py` | 抄底、个股信号、趋势起点 |

页面怎么用这些统计：合约结论卡按 `breakout|E|环境|方向` 取统计，平均≥0.08R 且前后两段都≥0.03R = 稳定优势；
≥0.08R 但有一段不赚 = 时灵时不灵（轻仓）；−0.03～0.08R = 基本不赚；更低 = 亏；不足100笔 = 样本少。
| `turtle_bt.py`（+`turtle_check*.py`） | 海龟日线组合：16个币安品种，20/55日突破、2N止损、1N风险定仓、加仓、分组上限、资金费；随机进场对照、参数/品种敏感性 |
| `ep_bt.py`（+`ep_check.py`） | 美股放量跳空（episodic pivot）：跳空≥8%量≥3倍，当天收盘/次日开盘进，止损跳空日低点，20天或破10日线离场；牛熊、前后段、随机日子对照；跳空向下做空 |
| `streak_bt.py` | 连亏减仓：按进场时间、只用已平仓的单子判断，连亏2/3笔半仓、资金曲线过滤 |
| `regime_def_bt.py` | 牛熊换5种分法（200日线/200日线+方向/金叉死叉/100日线/50日线）比较顺势做多、做空；结论：币改看比特币50日线可以做空，金银美股不变 |
| `parity_check.py` + `parity_page.js` | 对账：交易台页面的突破信号（`workbench_card.js` 里的 `brk`）和 `contract_bt.simulate`（出场F）在同一批K线上逐笔比较进场/离场，必须完全一致；改规则或改页面后先跑 |
| `workbench_card.js` | 交易台结论卡/首页清单/持仓总览的源码（内联在 gh-pages 的 index.html 里） |
| `indicator_bt.py` | 技术指标逐个拆开检验（均线、MACD、RSI、位置、日线、综合分）：指标看多/看空之后24小时的涨跌；每个指标翻多/翻空当进场信号的成绩（牛熊、前后段、U/次）。结论：只在顺大方向时有用 |
| `intraday_bt.py` | 金银日内短线（5分钟线，当天进当天出）：假跌破昨低收回、回踩日内低点不破、突破亚洲盘区间、突破昨高顺势；32组全亏 |
| `night_stop_bt.py` | 股票合约夜间止损：同一批交易时段突破信号，止损24小时有效 vs 只在美股交易时段有效（币安小时线约5个月，190只）；差别可忽略 |

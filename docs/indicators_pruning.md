# 指标实验室｜第二轮：因子去冗余（预注册，2026-09-30，计算之前提交）

> 主研究只控制了 5 个基础因子。这一轮在 74 个指标**互相之间**排除：找出最少几个彼此独立的因子，
> 判断其余指标是否只是它们的“换皮”；再检验把留下的因子合成一个分数后，做多能否扣成本赚钱。

## 1. 数据与变量

- 股票池、标签（t+1 开盘到 t+1+h 开盘）、持有期 h ∈ {1, 5, 20} 与主研究相同。
- 候选：全部 74 个指标。每个指标在当日可入选股票内取横截面居中秩分位 u ∈ (−0.5, 0.5)，缺失记 0（中性）。
- 因变量：标签在“可入选 & 标签有值”内的居中秩分位。
- 每个回归都包含：截距、市值分层哑变量（沪深300/中证500/中证1000）、申万一级行业哑变量。

## 2. 前向逐步选择（只用发现集 2012—2017）

1. 已选集合 S 起始为空。
2. 对每个候选 c，逐日做横截面回归 y ~ 基线 + S + c，取 c 的系数序列的 Newey-West t（滞后 max(h, 5)）。
3. 选 |t| 最大的候选加入 S；若最大 |t| ≤ 3 则停止。最多 20 个。
4. 三个持有期分别选择。

## 3. 确认与排除（验证集 2018—2022；测试集 2023—2026 只作一致性检查）

- **已选因子**：验证集联合回归中 |t| > 2 且与发现集同号 → “确认”；否则 “未确认”。
- **未入选的指标**：验证集里控制全部已选因子后的增量 t：
  |t| < 2 → **排除（被已选因子解释）**；2 ≤ |t| ≤ 3 → 边缘；|t| > 3 → **仍有独立信息（逐步法遗漏）**。
- 测试集在主研究中已按单个指标打开过（未做联合回归），因此只作一致性检查，不作为证据；真正的样本外是 2026-09-30 以后。

## 4. 相关结构（描述性）

- 发现集每 5 个交易日取一天，计算 74 个指标的横截面 Spearman 相关，取平均；按 1 − |ρ| 做平均联结层次聚类，
  在 |ρ| ≥ 0.7 处切分，列出“指标家族”。

## 5. 合成分数能不能赚钱

- 合成分数 = Σ bₖ · uₖ，bₖ 为发现集联合回归中已选因子的平均系数（按持有期分别确定）。
- 做多合成分数前 10%，与主研究相同的回测口径（t+1 开盘买、涨停买不进、跌停顺延、双边 0.3% / 压力 0.5%、相对股票池等权）。
- 报告验证集、测试集的年化超额与 90% CI；与单个最好的 A 级指标（log_amount_20）比较。

## 6. 方法自检（先于真实数据）

- 零假设模拟：逐步法应当一个因子都不选（或极少）。
- 埋入短期反转的模拟：应当选入 1~2 个反转类因子后停止，并把其余反转类指标判为“排除”。

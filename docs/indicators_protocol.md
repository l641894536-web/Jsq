# 指标实验室｜研究协议（预注册，2026-09-30）

> 问题：交易中常用的技术指标及其参数，到底能不能预测A股个股的未来走势？扣掉成本之后还能不能赚钱？
> 本协议与 `config/indicators.toml` 在计算任何“指标 vs 未来收益”之前提交。看过结果后不得增删指标、修改参数或判定标准；
> 确需修改的，写入文末变更记录，并同时保留原结果。

## 1. 数据与股票池

- 数据：chenditc/investment_data 2026-09-29 版 qlib 数据（sha256 已校验），含已退市股票的复权开高低收、成交量、成交额，以及中证指数历史成分。
- 股票池（t 日可入选，全部按时点）：
  - t 日为**中证全指成分**（自动排除 ST/*ST 与次新股；成分数据从 2011-08 起才完整）；
  - 上市 ≥60 个交易日；t 日有成交；
  - **t+1 日开盘有价格，且开盘未触及涨停**（买得进）。
- 涨跌停判定：当日涨跌幅 ≥ 限制 − 0.5%。限制：主板 10%；创业板 2020-08-24 前 10%、之后 20%；科创板 20%；北交所 30%。
- 市值代理：沪深300 / 中证500 / 中证1000 / 其余 四层（按时点成分）。行业：申万一级静态映射（上一项目生成）。
- 局限：没有市值、换手率、财报，也没有分钟数据。

## 2. 标签与样本切分

- 信号在 t 日收盘计算；**t+1 日开盘买入，t+1+h 日开盘卖出**，h ∈ {1, 5, 20}；收益为开盘到开盘的复权收益。
- 切分：发现集 2012-01 ~ 2017-12；验证集 2018-01 ~ 2022-12（主要判定依据）；**最终测试集 2023-01 ~ 2026-09，全部判定写完后只打开一次**。

## 3. 指标定义（74 个信号）

记号：C/O/H/L 为复权收盘/开盘/最高/最低，V 为成交量，A 为成交额，r = C/C₋₁ − 1，MAₙ 为 n 日简单均线。

| 信号 | 定义 |
|---|---|
| bias_n | C / MAₙ − 1，n = 5,10,20,60,120,250 |
| ma_align | MA5>MA10>MA20>MA60 记 +1，完全反向记 −1，其余 0 |
| macross_s_l | MA_s / MA_l − 1，(5,20)(10,60)(20,120) |
| ret_n | C / C₋ₙ − 1，n = 1,5,20,60,120,250 |
| mom_12_1 | C₋₂₀ / C₋₂₅₀ − 1（跳过最近一个月） |
| macd_dif / dea / hist | DIF = EMA_f − EMA_s，DEA = EMA_m(DIF)，柱 = 2(DIF−DEA)，均除以 C；参数 (12,26,9) 与 (6,13,5) |
| rsi_n | Wilder RSI，n = 6,14,24 |
| kdj_k / d / j | RSV = (C − 9日最低)/(9日最高 − 9日最低)×100；K = ⅔K₋₁ + ⅓RSV；D = ⅔D₋₁ + ⅓K；J = 3K − 2D |
| wr_14 | (14日最高 − C)/(14日最高 − 14日最低)×100（国内软件口径，越大越超卖） |

## 4. 检验流程（顺序固定）

**第 0 步：误报率校准。** 在没有任何可预测性的模拟股票数据上跑完整流程，确认 |t|>3 且 FDR 显著的信号比例接近 0；再在埋入一个已知信号的模拟数据上确认能找回（检验力）。

**第 1 步：预测力（发现集、验证集）。** 每个信号 × 每个持有期：
- 每日横截面 Rank IC（股票池内指标秩与标签秩的相关）；IC 均值、IC_IR、Newey-West t 值（滞后 = max(h, 5)）；
- 按指标分 10 组，各组平均收益、最高组 − 最低组、单调性；事件类信号比较“有事件 − 股票池平均”。

**第 2 步：多重检验（验证集）。** 74 × 3 = 222 项：
- BH-FDR（q < 0.05）；
- 最大 t 统计量自助法（White Reality Check 思路，20 日块）给出族错误率校正后的 p 值；
- 显著门槛：验证集 |t| > 3，q < 0.05，且方向与发现集一致。

**第 3 步：增量信息（验证集，只对第 2 步显著的信号）。** 每日横截面回归（Fama-MacBeth）：标签 ~ 信号 + 控制变量（ret_1、ret_20、mom_12_1、vol_20、log_amount_20，市值分层哑变量，申万一级行业哑变量），信号系数的 NW |t| > 2 才算有增量信息。控制变量本身记为“基础因子”。

**第 4 步：可交易性（发现集定方向，验证集检验）。**
- 做多排名前 10%（方向由发现集 IC 符号决定），等权，每 h 日调仓；事件类信号持有全部出现事件的股票；
- t+1 开盘涨停不买；卖出日开盘跌停则顺延（最多 5 天）；
- 双边成本 0.3%（压力测试 0.5%）；相对股票池等权的年化超额，块自助法 90% 置信区间；报告换手率、被涨跌停阻挡的比例。

**第 5 步：稳健性（验证集）。**
- 参数平台：同一参数族里，最佳参数的相邻参数须同号、且 |t| ≥ 最佳 |t| 的 50%；
- 按市值分层（沪深300/中证500/中证1000/其余）和市场环境（中证800 均线法：牛/震荡/熊）分别计算 IC；
- 安慰剂：随机打乱信号在股票间的对应关系，保持换手率不变。

**第 6 步：最终测试集（只打开一次）。** 在第 1~5 步的判定全部写入报告并提交之后运行。

## 5. 判定标准

| 等级 | 条件 |
|---|---|
| **A 可用** | 验证集：|t|>3、q<0.05、方向与发现集一致；有增量信息（FM |t|>2）；扣 0.3% 成本后前 10% 组合超额 > 0 且 90%CI 下限 > 0；参数平台成立；**最终测试集**：IC 同号且 |t|>2，扣成本超额 > 0 |
| **B 有信息、难赚钱** | 验证集满足 |t|>3、q<0.05、方向一致，但增量信息、可交易性、参数平台或最终测试至少一项不满足 |
| **C 无效** | 验证集不满足显著条件 |

另外单独标注：**“基础因子”**（控制变量本身）；**“仅回避用”**（方向为负的事件信号：只能用来回避，无法用做多组合检验）。

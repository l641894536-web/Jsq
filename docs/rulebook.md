## R1｜拥挤后跑输

- **定义**：行业（申万一级）或主题组合的成交额占全A比重，处于自身过去 750 个交易日的 99% 分位以上（向上穿越；回落到 89% 以下才重新计数；同一标的 20 日内只计一次）。
- **预测**：之后 20 个交易日、60 个交易日相对市场跑输。
- **样本内证据**：20 日 −1.3%、60 日 −2.0%（相对同板块平常日子）；控制过去 20 日动量后仍为 −1.2%、−2.2%。
  申万一级、东财细分行业、等权行业指数三个口径全部 A 级（约 100 个独立簇）。
- **用法**：回避或低配，不是做空信号。
- **组合层面（第三轮）**：被 R1 剔除的“拥挤篮子”相对全行业等权年化 −7%~−10%（4 个版本 A/B 级）；
  但在 31 个行业等权组合里平均只剔除约 6 个，所以组合只多出年化约 +1%（4 个版本都为正，均不显著）。持仓越集中，R1 越有用。
- **样本外判定**：≥10 个独立簇后，若 60 日平均超额 < 0 且 90%CI 上限 < 0 视为“样本外确认”；若平均 > 0 视为“样本外失效”。

## R2｜强势板块 5%~7% 大跌后看次日

- **定义**：前一交易日处于强势（60 日超额排名前 5 且 60 日超额 ≥10%）的行业，单日跌幅在 [5%, 7%)；看次日涨跌。
- **预测**：次日续跌时，“趋势结束”的概率高于次日收涨。趋势结束 = **从次日收盘起** 60 日内相对强弱未创大跌前 60 日新高，且（从次日收盘起的）60 日超额 < 0。
- **样本内证据**：5%~7% 档的趋势结束比例差 +23 / +18 / +29 个百分点（申万一级、东财细分行业、等权；90%CI 均不含 0）。
  v1.0 用“从大跌日收盘起算”的口径为 +25~+34pp，其中一部分是次日本身造成的机械效应。
  **证据强度须打折**：5%~7% 这一档是第二轮拆分中挑出来的（H3），多重校正后只有东财细分口径 q≈0.05；
  不分跌幅档（≥5%）时修正口径只有 +12~+14pp（申万一级 C 级、东财细分 A 级、等权 C 级）。跌幅 ≥7% 时不适用。
- **重要限制（第三轮）**：R2 预测的是“这轮主线还能不能再创新高”，**不预测平均收益**——续跌组与收涨组之后 20/60 日的平均超额没有差别（两组 60 日都约 −3%）。
  组合回测里“剔除次日续跌的强势行业”多出的年化 +4%，换成“次日收涨就剔除”也有 +3.5%，说明那来自“离开大跌后的强势行业”，与次日无关。
- **用法**：判断主线形态（次日续跌 → 大概率不再创新高，不要等“再创新高”）；**不要据此期望超额收益**。
- **样本外判定**：≥20 个事件后，若“续跌组结束率 − 收涨组结束率”> 0 且 90%CI 下限 > 0 视为确认；若 ≤ 0 视为失效。

## 观察级（证据 B 级或不够稳健，不作为规则，只记录）

- **成交集中度反弹**：前 5% 个股成交占比 ≥45%（多为恐慌/救市日）之后，全A 20 日平均 +6.3%。B 级，一个版本为 C。
- **全市场垃圾股信号**：小微盘 20 日极端跑赢后，40 日内市场见顶的概率约为基准的 1.4~1.7 倍。C/B 级。
- **O3 强势行业反转**（第三轮看过结果后发现，未经预注册检验）：强势行业（60 日超额排名前 5 且 ≥10%）等权组合，
  每 5 日调仓，相对全行业等权年化约 −11%（样本内）。与研究F“行业动量亏钱”一致。样本外在 scoreboard 中跟踪。

## 明确不用的“经验”（被数据否定或未被支持）

- 成交占比到 40%/45%/50% 就见顶；
- 行业内垃圾股补涨＝主线后期（方向相反）；
- 按天数判断主线阶段；
- 拥挤或强势确认后追入，再靠止盈、均线、占比回落等规则退出（研究G：入场本身无优势）；
- 把 R2（次日确认）当成收益信号（它只预测形态，不预测平均收益）；
- 用均线或动量划分牛熊后切换策略（识别滞后吃掉全部好处）；
- 风格切换领先信号（未找到）。

# 研究协议（预注册）

> 目的：把“A股规律”变成**可以被数据推翻**的命题。
> 规则：先写定义、假设、检验方法和通过标准，再看结果；结果出来以后不许回头改定义去“凑”显著。

所有数值参数都在 [`config/default.toml`](../config/default.toml)，本文件解释它们为什么这样定、怎么检验。

## 0. 通用规则

### 0.1 数据与样本
| 项目 | 约定 |
|---|---|
| 研究区间 | 2015-01-01 起（数据从 2010 年取，前几年只做滚动窗口预热） |
| 行业口径 | 申万一级（2021 版，31 个）；可替换为二级行业/概念，格式见 `ashare_lab/data/market.py` |
| 市场基准 | 中证全指 000985 |
| 成交占比分母 | 31 个申万一级行业成交额之和（与分子口径一致，≈全A） |
| 主题组合 | TMT=电子+计算机+通信+传媒 等，见 `[groups]` |
| 风格 | 国证成长 399370 / 国证价值 399371；附加 中证1000/沪深300 |
| 个股（研究E、成交集中度） | 后复权收盘价、成交额、换手率；行业归属与财报按**生效/公告日期**点对点使用 |

### 0.2 防前视偏差清单
- 所有信号在 t 日只用 t 日及以前的数据；分位数用滚动/扩展窗口，不用全样本分位。
- 默认 `entry_lag=1`：t 日收盘确认信号，t+1 日收盘入场。研究C另报告 t 日收盘入场（L0）。
- zigzag 的峰/谷是**事后**才知道的（价格反向走满阈值那天才确认），只能当“结果”，不能当信号；报告里单列“确认日”，显示现实中最早什么时候能认出顶部。
- 财报按公告日生效；行业归属按计入日期生效。
- 研究F 的“事后标签”用了未来数据，只作为“完美识别环境”的理论上限，不参与任何可交易结论。

### 0.3 统计推断（为什么不用普通 t 检验）
A股十年里真正独立的“主线/拥挤/大跌/风格切换”只有几个到几十个，而且同一轮行情会连续触发很多天、多个行业同时触发。普通检验会把一件事数成几十件事。所以：

1. **事件去簇**：穿越型事件回落到“阈值−间隔”以下才重新计数；同一标的两次事件间隔 ≥ N 日。
2. **独立簇**：再把相隔 ≤20 个交易日的事件（不论哪个行业）归为一簇，**证据等级按簇数算**。
3. **p 值**：
   - 事件研究：**整体时间平移置换**——所有事件日期整体平移同一随机量，保留事件扎堆结构和指标自相关；
   - 分组比较（研究C）：**按日期簇自助法**；Fisher 检验只作对照；
   - 预测力（研究D）：**max(循环平移检验 p, 按独立样本数 N/h 的 t 检验 p)**。在随机游走上模拟，单用 Newey-West 或单用平移检验，h=60/120 日时误报率可达 10%~15%；两者取大后约 0%~6.5%（名义 5%），见 `tests/test_stats_size.py`。
4. **多重检验**：每张结果表是一个检验族，做 Benjamini-Hochberg 校正（q 值）。
5. **前后两段一致**：以 2020-12-31 为界，事件相对基准的差值在两段必须同号。
6. **对照组**：永远和“同一标的的平常日子”比，而不是和 0 比；研究B/C 额外和“同样强势但没发生该事件”的日子比，把“拥挤/大跌”的效应和“动量”分开。

### 0.4 证据等级
| 等级 | 条件 | 含义 |
|---|---|---|
| **A 强证据** | 独立簇 ≥ 20，q < 0.05，前后两段同向 | 可以写进规律库，但仍需样本外跟踪 |
| **B 中等证据** | 独立簇 ≥ 10，q < 0.10，前后两段同向 | 可以作为参考规则，标注不确定性 |
| **C 弱/不显著** | 其余 | 不能当规律用；可作为观察线索 |
| **D 样本不足** | 独立簇 < 5 | 不下结论，只看逐个事件明细 |

### 0.5 方法自检（在跑真实数据之前已完成）
- **检验力**：在埋入了规律的合成数据上，方法能找回主线波段（≥75%）、扩散顺序（A 级）、大跌特征（A 级）。
- **误报率**：在什么都没埋的合成数据上（8 个随机种子、1156 项检验），A/B 级比例约 1%。
- 两项都写成了自动化测试（`tests/test_studies.py`），改代码后必须仍然通过。

## 研究A｜主线生命周期

**问题**：主线从第一次超额收益出现，到加速、拥挤、顶部、退潮到底分别多长时间？

**定义**
- 主线：行业/中证全指 的相对强弱线（RS）上，zigzag(20%) 的上涨段，谷→峰超额 ≥ 30%、≥ 20 个交易日，且期间 60 日超额排名进过前 3。
- 节点：谷底（事后）→ 首次超额（20日超额首次≥5%）→ 加速（首次≥15%）→ 拥挤（成交占比到自身 3 年 95% 分位）→ 相对顶部（事后）→ 退潮底部（事后）。

**要回答的具体问题（描述性，无显著性检验）**
- A1 各阶段时长的中位数和四分位距；离散度 = IQR/中位数，**>1 即判定“不能按天数判断阶段”**。
- A2 退潮时长/上涨时长。
- A3 拥挤信号出现在顶部之前的比例，以及出现后还剩多少超额（带自助法置信区间）。
- A4 看到信号后一直持有到退潮底部，超额是正是负（“不卖”的代价）。
- A5 前后两段的时长是否稳定。

**陷阱**：右截断（进行中的主线不进分布，单列）；左截断（数据起点附近的主线真实起点更早）；一级行业粒度粗。

## 研究B｜拥挤度

**问题**：成交占比达到 30%/40%/45%/50% 以后，板块未来 5/10/20/60 日怎么样？

**预注册假设**
- H-B1：主题组合成交占比向上穿越绝对阈值后，未来 h 日超额收益**低于**该组合平常水平（拥挤→回落）。
- H-B2：同上，但与“同样强势（20日超额处于历史前20%）但不拥挤”的日子比，仍然更差——即拥挤本身有害，而不只是动量衰减。
- H-B3（相对口径）：组合或单行业的成交占比到自身历史 90/95/99% 分位后，未来超额更差。
- H-B4（可选，需个股）：成交额前 5% 个股的成交占比穿越 40/45/50% 后，全A 未来收益更差。

**通过标准**：见 0.4；45%/50% 阈值历史上只有极少数独立事件，**预期为 D 级**——这本身就是结论：这些阈值的“经验”来自一两次案例，不是统计规律。

## 研究C｜主线大跌

**问题**：强势板块单日 −5%/−7%/−10% 以后，什么时候是机会，什么时候是趋势结束？

**定义**
- 强势：前一日 60日超额排名前 5 且 60日超额 ≥ 10%。
- 结果（事后）：机会 = 20 日内收复大跌前收盘且 20 日超额>0；趋势结束 = 60 日内 RS 不创新高且 60 日超额<0。

**预注册假设**
- H-C1：强势板块大跌后的未来超额，与“强势但没大跌”的日子没有差别（零假设；若拒绝，看方向）。
- H-C2：以下大跌当日可观测的特征能区分“机会/结束”（逐个检验，BH 校正）：
  当日跌幅、当日超额（行业自身 vs 系统性）、市场当日涨跌、前20日涨幅、前60日超额、放量倍数、成交占比分位、偏离20日线、距RS高点天数、前60日大跌次数。
- H-C3：次日续跌比次日收涨更可能是趋势结束（t+1 才知道）。

**陷阱**：一级行业 −7%/−10% 极少；系统性暴跌日多个行业同时入样（已用日期簇处理）；指数层面忽略跌停无法成交。

## 研究D｜风格切换

**问题**：成长→价值、价值→成长之前有没有可观察的领先信号？

**定义**：切换点 = log(成长/价值) 的 zigzag(10%) 峰/谷，每段 ≥ 40 日。

**候选信号与预注册方向**（信号越高 → 越可能成长→价值，即预测力检验中 IC<0 为符合假设）
| 信号 | 逻辑 |
|---|---|
| 相对动量 60/120 日 | 风格走得太远会均值回归 |
| 相对偏离年线 | 同上 |
| 成交额比 z 值 | 成长交易过热 |
| 成长拥挤度（TMT 成交占比分位） | 同上 |
| 10Y 国债 60 日变化 | 利率上行压制长久期的成长股 |
| 期限利差 | 曲线陡峭 → 复苏 → 价值/周期 |
| 市场 60 日动量 | 风险偏好 |
| 相对波动率 | 成长波动放大往往在末期 |

**检验**：(a) 预测力 IC（见 0.3 第 3 条）；(b) 极端分位预警后 60 日内切换的精确率 vs 基准概率（二项检验）+ 召回率；(c) 切换前信号画像——**仅描述**，因为切换点是按价格事后挑的，价格类信号在峰前必然偏高。

## 研究E｜补涨扩散

**问题**：龙头→二线→垃圾股扩散，是否真的意味着行情进入后段？

**定义**：每 20 日按当时信息分层——龙头=行业内流通市值前 20% 且盈利；二线=40%~80%且盈利；尾部=市值后 40% 或亏损。

**预注册假设**
- H-E1：主线后段（谷→顶的最后三分之一）的“尾部−龙头”收益差，显著高于早段（配对 Wilcoxon）。
- H-E2：主线早段龙头跑赢尾部（符号检验）。
- H-E3：主线后段尾部跑赢龙头（符号检验）。
- H-E4（可交易）：强势行业出现“尾部−龙头 10 日收益差处于历史 90% 分位”后，40 日内见主线顶部的概率高于强势行业的平常水平，未来超额更差。
- H-E5（全市场）：小票/垃圾股 20 日相对强度到历史 90% 分位后，40 日内市场见顶的概率更高。

**陷阱**：“垃圾股”无统一定义；只用当前上市公司会有幸存者偏差（fetch 已合并申万历史分类里的退市股代码）。

## 研究F｜市场环境

**问题**：牛市、熊市、震荡市分别应该用什么策略？分环境是否真的比一套策略打天下更好？

**环境**：均线法（年线+斜率）、动量法（120 日 ±15%），新环境需连续 10 天才确认；事后标签只作上限。

**候选策略**（刻意简单）：行业动量、行业反转、均线择时、超跌买入、红利/防御、小盘、买入持有、空仓。

**预注册假设**
- H-F1：各环境下的最优策略不同，且前后两段一致。
- H-F2（核心）：逐年滚动、只用过去数据为每种环境挑最优策略，样本外表现**显著优于**同样滚动但不分环境的单一最优策略（移动块自助法 90% CI 不跨 0）。
- 对照：事后标签版本给出“如果能完美识别环境”的上限；实时版本与上限的差距 = 环境识别滞后的代价。

## 第二轮：拆解研究（2026-09-30 预注册，先于真实数据运行提交）

第一轮的结论里有三条值得往下拆：（1）主线的难点在“退出”；（2）次日确认规律；（3）成交占比创自身 99% 分位后跑输。
另外，第一轮用的是申万一级这种粗口径，需要在更细的行业口径上复现。参数见 `config/default.toml` 的 `[exit]`、`[decompose]`。

### R2-1｜细分行业口径复现
- 用东方财富 86 个行业（粒度接近申万二级）重建行业指数（成分股 <10 只的行业不参与），重跑研究 A、B、C、E。
- 通过标准：第一轮的 A/B 级结论在细口径上方向一致；证据等级允许变化，但方向相反即判定“对口径不稳健”。

### 研究G｜退出规则
**问题**：主线一旦确认，用什么规则退出能保住最多超额？
- 入场（t 日可观测）：E1 强势确认（60 日超额排名前 3 且 ≥15%）；E2 拥挤确认（成交占比到 3 年 95% 分位且 60 日超额 ≥10%）。同一行业 120 日内只入场一次。
- 评估：入场后 250 日窗口内，按规则持有该行业、退出后持有市场，计算累计相对收益（行业/市场 −1）。
- 退出规则：固定持有 60/120 日；相对强弱从持有期高点回撤 10%/15%/20%；收盘连续 2 日跌破 20/60 日线；相对强弱连续 2 日跌破其 60 日均线；成交占比分位从 ≥95% 回落到 <80%；单日跌 ≥5% 且次日续跌；持有满 250 日。
- 预注册假设（每条都和“固定持有 120 日”配对比较，按日期簇自助法，BH 校正）：
  - H-G1：相对强弱回撤 15% 止盈优于固定持有；
  - H-G2：“大跌+次日续跌”退出优于固定持有；
  - H-G3：成交占比回落退出优于固定持有；
  - 其余规则作为同一检验族一起报告。

### 研究H｜拆解
- **H1 主线按类型**（成长/周期/消费/金融稳定）：各类型的阶段时长、拥挤后剩余超额、持有到底的超额；Kruskal-Wallis 检验类型间差异（描述为主）。
- **H2 拥挤 vs 动量**（预注册 H-B5）：成交占比创自身 99% 分位后的跑输，在与“同一板块、过去 20 日超额处于同一五分位、但占比 <90% 分位”的日子配对后仍然存在。
- **H3 次日确认的异质性**：按跌幅档（5%~7% / ≥7%）、行业自身 vs 系统性（当日超额 ≤−3%）、大跌前是否拥挤（占比分位 ≥90%）、市场环境（均线法）、前后两段拆分，分别计算“次日续跌 − 次日收涨”的趋势结束比例差，并检验组间差异（交互作用）。全部为探索性，BH 校正。

# Jsq · A股规律库

把“A股规律”变成**可以被数据推翻的命题**，而不是凭感觉讲故事。

不只看K线：同时用**成交占比（拥挤度）、行业相对强弱、风格相对线、个股分层、利率、市场环境**，
对 2015—2026 年的 A 股做六项预注册的验证研究。每个结论都附带样本量、置信区间、对照组、
多重检验校正和前后两段一致性检查，最后给出 A/B/C/D 证据等级。

## 真实数据结论（截至 2026-09-29）

**→ [results/real_2026-09-29/结论与判断.md](results/real_2026-09-29/结论与判断.md)**（一页结论 + 逐项判断 + 稳健性 + 数据局限）

简要：
- **能写进规律库的**：强势板块跌 5%~7% 后看次日，续跌时“趋势结束”概率明显更高（A 级，细分行业复现）；板块成交占比创自身 3 年 99% 分位后 1~3 个月平均跑输，且控制动量后仍成立（A 级）；主线阶段不能按天数判断。
- **第二轮修正**：拥挤既不是卖点也不是买点——实时按“强势/拥挤确认”入场，250 日内平均相对收益约为 0，而且没有任何退出规则能显著改善（研究G）。
- **第三轮**：R1 拥挤回避在组合里方向稳定但增益小（年化约 +1%）；R2 次日确认原证据含机械效应，修正后只能预测“能否再创新高”，不预测收益（安慰剂检验）。
  规则冻结在 [docs/rulebook.md](docs/rulebook.md)，样本外从 2026-10-01 起用 `monitor` / `scoreboard` 跟踪。
- **没被数据支持的**：“成交占比到 40/45/50% 就见顶”；“行业内垃圾股补涨＝后期”（方向相反）；风格切换的领先信号；实时分环境换策略。

## 六项研究

| | 问题 | 核心做法 | 需要的数据 |
|---|---|---|---|
| **A 主线生命周期** | 主线从第一次超额 → 加速 → 拥挤 → 顶部 → 退潮到底，各多长？ | 行业相对强弱线 zigzag 识别主线；统计各阶段时长的分布和离散度；看到信号后还剩多少空间 | 行业指数 |
| **B 拥挤度** | 成交占比到 30/40/45/50% 以后，未来 5/10/20/60 日怎样？ | 主题组合（如 TMT）成交占比穿越事件；对照“平常日子”和“强势但不拥挤”的日子 | 行业指数（+个股：成交集中度） |
| **C 主线大跌** | 强势板块单日 −5/−7/−10% 后，何时是机会、何时是趋势结束？ | 大跌事件 → 机会/中性/结束；10 个大跌当日可观测特征逐个检验区分度 | 行业指数 |
| **D 风格切换** | 成长↔价值切换前有没有领先信号？ | 9 个候选信号的预测力（IC）+ 极端分位预警的精确率/召回率 | 风格指数、国债收益率 |
| **E 补涨扩散** | 龙头→二线→垃圾股扩散是否意味着行情进入后段？ | 行业内按市值/盈利分层，比较主线早/中/后段各层收益；扩散信号→见顶概率 | 个股（无个股时只跑指数代理） |
| **F 市场环境** | 牛/熊/震荡市分别该用什么策略？ | 实时环境划分 × 7 个简单策略；逐年滚动的样本外检验：分环境切换 vs 一套策略 | 行业与宽基指数 |
| **G 退出规则**（第二轮） | 主线确认后怎么退出？ | 两种实时入场 × 11 种退出规则，同一笔入场配对比较 | 行业指数 |
| **H 拆解**（第二轮） | 稳健结论在什么条件下成立？ | 主线按类型拆分；拥挤 vs 动量配对；次日确认的异质性 | 行业指数 |
| **I 规律组合**（第三轮） | 扣成本后还有经济意义吗？ | R1/R2 做成行业组合，块自助法检验超额，安慰剂对照 | 行业指数 |

每项研究的定义、假设、检验方法和通过标准写在 **[docs/protocol.md](docs/protocol.md)**（预注册），参数在 **[config/default.toml](config/default.toml)**。

## 快速开始

```bash
pip install -e ".[data,dev]"

# 1. 先在合成数据上检查整个流程（不需要网络，约 15 秒）

# 2. 下载真实数据（申万一级行业、宽基/风格指数、国债收益率；几分钟）

# 4. 跑全部研究，报告在 reports/（00_总览.md + 每项研究一份 + csv/ 原始表）
python -m ashare_lab run all

# 稳健性：临时覆盖参数（报告里会注明），比如改成信号日收盘入场

# 测试
pytest

# 样本外跟踪（每次拿到新数据后运行）

python -m ashare_lab --config config/qlib.toml scoreboard   # 已到期信号的实际表现
```

## 怎么读报告

- **证据等级**：A=独立簇≥20、FDR 校正后 q<0.05、前后两段同向；B=独立簇≥10、q<0.10、同向；C=不显著或前后不一致；D=独立簇<5，不下结论。
- **独立簇**：同一轮行情里连续触发、或多个行业同一天触发，只算一份证据（相隔 ≤20 个交易日归为一簇）。
- **基准/对照**：永远和“同一板块的平常日子”比，而不是和 0 比；拥挤和大跌还额外和“同样强势但没发生该事件”的日子比，把拥挤/大跌的效应和动量分开。
- **事后 vs 实时**：顶部、底部、切换点都是事后才能确认的，报告里单列“确认日”——现实中最早什么时候能认出来。
- **“不显著”也是结论**：比如 45%/50% 成交占比在十年里只有一两次，报告会标 D 级并逐个列出事件——说明这类“经验”来自个案，不是统计规律。

## 方法自检（已完成，写成了自动化测试）

在读真实数据的结论之前，先确认方法本身靠得住：

- **检验力**：在埋入了已知规律的合成数据上，能找回 ≥75% 的主线波段，扩散顺序和大跌特征被识别为 A 级。
- **误报率**：在什么规律都没有的合成数据上（8 个随机种子、1156 项检验），被判为 A/B 级的约 1%。
- **预测力检验的实际误报率**：长周期重叠收益 + 持续性信号会让 Newey-West 等常规检验在 5% 水平下误报 10%~15%；
  本项目的 IC 检验取“循环平移检验”与“按独立样本数 t 检验”中较大的 p 值，实测误报率约 0%~6.5%（`tests/test_stats_size.py`）。

## 已知局限

- 申万一级行业粒度粗，真实主线常在二/三级行业或概念（如 CPO、算力）；把 `sector_daily.csv` 换成二级行业即可重跑。
- 2015—2026 只有 2~3 轮完整牛熊，主线、风格切换、强势板块大跌的独立样本都很少，多数结论的置信区间会很宽。
- 指数层面忽略涨跌停无法成交、冲击成本、ETF 跟踪误差。
- 规律库里的结论只描述历史；2026 年以后的数据才是真正的样本外。

# 指标实验室：技术指标到底能不能预测个股走势？

第二个项目（`indicator_lab/`）：把交易里常用的 **74 个技术指标/参数**（均线乖离、MACD、RSI、KDJ、布林、量价、涨停、各种“金叉/突破”事件……）
放到 2012—2026 年全部A股（含已退市）上，逐个检验“它能不能预测未来 1/5/20 日的涨跌、扣成本后能不能赚钱”。

**协议先于结果**：[docs/indicators_protocol.md](docs/indicators_protocol.md)（指标定义、切分、判定标准、变更记录）+ [config/indicators.toml](config/indicators.toml)。

|---|---|---|
| 0 误报率校准 | 在“什么规律都没有”的模拟A股上跑整套流程，看会不会误报；再埋入一个已知信号看能不能找回 | `results/indicators_2026-09-29/calibration/` |

## 指标实验室结论（截至 2026-09-29）

**→ [results/indicators_2026-09-29/结论与判断.md](results/indicators_2026-09-29/结论与判断.md)**

- **能预测，而且很稳定，但方向几乎一致：“越热越差”。** 222 项检验里 191 项在验证集显著（零假设模拟里 1332 项只有 1 项），
  并且在只打开一次的测试集（2023-01 ~ 2026-09）里**全部同号**、179 项 |t|>2。
- **信息集中在“最热的 10%”**（每年跑输 16%~31%），**最冷的 10% 并不会涨**——所以“买超跌”多数不赚钱。
- **经典买点买入后全部跑输股票池**：MACD 金叉、KDJ 低位金叉、5/20 日均线金叉、RSI6 超卖、突破 20 日新高；涨停次日追入 20 日平均跑输 4.2%。
- **很多指标是换皮**：长周期均线/乖离、MACD 的 DIF/DEA、60/120 日涨幅控制基础因子后没有增量信息；**参数不用调**，超短参数样本外衰减最多。
- **A 级只有 3 个**：低成交额（小盘/低流动性溢价，测试集扣成本后年化 12~16%，容量有限）；
  过去 20 日无涨停、未创 250 日新高（本质是回避规则，后者超额约 0）。12-1 月动量在A股无效。
- **指数/行业择时无效**（次要研究）：同一批指标用于宽基与 31 个行业择时，408 项 0 项显著，择时夏普多数不如买入持有——技术指标的信息是横截面的，不是时间序列的。

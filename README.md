# Jsq · A股规律库

把“A股规律”变成**可以被数据推翻的命题**，而不是凭感觉讲故事。

不只看K线：同时用**成交占比（拥挤度）、行业相对强弱、风格相对线、个股分层、利率、市场环境**，
对 2015—2026 年的 A 股做六项预注册的验证研究。每个结论都附带样本量、置信区间、对照组、
多重检验校正和前后两段一致性检查，最后给出 A/B/C/D 证据等级。

## 六项研究

| | 问题 | 核心做法 | 需要的数据 |
|---|---|---|---|
| **A 主线生命周期** | 主线从第一次超额 → 加速 → 拥挤 → 顶部 → 退潮到底，各多长？ | 行业相对强弱线 zigzag 识别主线；统计各阶段时长的分布和离散度；看到信号后还剩多少空间 | 行业指数 |
| **B 拥挤度** | 成交占比到 30/40/45/50% 以后，未来 5/10/20/60 日怎样？ | 主题组合（如 TMT）成交占比穿越事件；对照“平常日子”和“强势但不拥挤”的日子 | 行业指数（+个股：成交集中度） |
| **C 主线大跌** | 强势板块单日 −5/−7/−10% 后，何时是机会、何时是趋势结束？ | 大跌事件 → 机会/中性/结束；10 个大跌当日可观测特征逐个检验区分度 | 行业指数 |
| **D 风格切换** | 成长↔价值切换前有没有领先信号？ | 9 个候选信号的预测力（IC）+ 极端分位预警的精确率/召回率 | 风格指数、国债收益率 |
| **E 补涨扩散** | 龙头→二线→垃圾股扩散是否意味着行情进入后段？ | 行业内按市值/盈利分层，比较主线早/中/后段各层收益；扩散信号→见顶概率 | 个股（无个股时只跑指数代理） |
| **F 市场环境** | 牛/熊/震荡市分别该用什么策略？ | 实时环境划分 × 7 个简单策略；逐年滚动的样本外检验：分环境切换 vs 一套策略 | 行业与宽基指数 |

每项研究的定义、假设、检验方法和通过标准写在 **[docs/protocol.md](docs/protocol.md)**（预注册），参数在 **[config/default.toml](config/default.toml)**。

## 快速开始

```bash
pip install -e ".[data,dev]"

# 1. 先在合成数据上检查整个流程（不需要网络，约 15 秒）
python -m ashare_lab run all --synthetic

# 2. 下载真实数据（申万一级行业、宽基/风格指数、国债收益率；几分钟）
python -m ashare_lab fetch
#    需要研究E（龙头/二线/垃圾股）和成交集中度时，再下载个股（约 1~2 小时，可断点续传）
python -m ashare_lab fetch --stocks

# 3. 检查数据质量（覆盖区间、缺失、各主题组合历史上到过几次 30%/40%/45%/50%）
python -m ashare_lab check

# 4. 跑全部研究，报告在 reports/（00_总览.md + 每项研究一份 + csv/ 原始表）
python -m ashare_lab run all

# 稳健性：临时覆盖参数（报告里会注明），比如改成信号日收盘入场
python -m ashare_lab run B C --set common.entry_lag=0 --out reports/robust_lag0

# 测试
pytest
```

数据下载依赖 akshare，需要能访问 `swsresearch.com`（申万指数）和 `eastmoney.com`（指数、个股、国债、财报）。
也可以用 Wind/Choice/Tushare 等数据：整理成 `ashare_lab/data/market.py` 顶部说明的标准 CSV 格式放进 `data/` 即可。

## 怎么读报告

- **证据等级**：A=独立簇≥20、FDR 校正后 q<0.05、前后两段同向；B=独立簇≥10、q<0.10、同向；C=不显著或前后不一致；D=独立簇<5，不下结论。
- **独立簇**：同一轮行情里连续触发、或多个行业同一天触发，只算一份证据（相隔 ≤20 个交易日归为一簇）。
- **基准/对照**：永远和“同一板块的平常日子”比，而不是和 0 比；拥挤和大跌还额外和“同样强势但没发生该事件”的日子比，把拥挤/大跌的效应和动量分开。
- **事后 vs 实时**：顶部、底部、切换点都是事后才能确认的，报告里单列“确认日”——现实中最早什么时候能认出来。
- **“不显著”也是结论**：比如 45%/50% 成交占比在十年里只有一两次，报告会标 D 级并逐个列出事件——说明这类“经验”来自个案，不是统计规律。

## 方法自检（已完成，写成了自动化测试）

在读真实数据的结论之前，先确认方法本身靠得住：

- **检验力**：在埋入了已知规律的合成数据上，能找回 ≥75% 的主线波段，扩散顺序和大跌特征被识别为 A 级。
- **误报率**：在什么规律都没有的合成数据上（8 个随机种子、1156 项检验），被判为 A/B 级的约 1%。
- **预测力检验的实际误报率**：长周期重叠收益 + 持续性信号会让 Newey-West 等常规检验在 5% 水平下误报 10%~15%；
  本项目的 IC 检验取“循环平移检验”与“按独立样本数 t 检验”中较大的 p 值，实测误报率约 0%~6.5%（`tests/test_stats_size.py`）。

## 已知局限

- 申万一级行业粒度粗，真实主线常在二/三级行业或概念（如 CPO、算力）；把 `sector_daily.csv` 换成二级行业即可重跑。
- 2015—2026 只有 2~3 轮完整牛熊，主线、风格切换、强势板块大跌的独立样本都很少，多数结论的置信区间会很宽。
- 指数层面忽略涨跌停无法成交、冲击成本、ETF 跟踪误差。
- 规律库里的结论只描述历史；2026 年以后的数据才是真正的样本外。

# Jsq：币安合约 资金费率 / K线 多空策略研究工具

用来回答两个问题：

1. **资金费率、溢价、K 线这些数据，能不能预测接下来的涨跌？** → 因子预测力分析（IC）
2. **哪些策略在哪些标的上真的有效（胜率、收益、回撤）？** → 13 个策略 × 6 种出场方式 × 多参数，滚动样本外回测

标的：BTC/ETH、黄金、白银、原油、美股等币安 U 本位永续合约。持仓时间不固定（几小时到几天），由信号和止损/止盈/超时决定。

## 安装

```bash
pip install -r requirements.txt
pip install numba        # 可选，回测提速
```

国内网络访问币安需要代理：所有联网命令都支持 `--proxy http://127.0.0.1:7890`，或设置环境变量 `HTTPS_PROXY`。

## 使用

```bash
# 0. 离线体验（合成数据跑通全流程）
python -m jsq demo

# 1. 找出币安上黄金/白银/原油/美股合约的真实代码，写入 symbols.txt（可手动编辑）
python -m jsq discover --save

# 2. 下载数据（K线 + 溢价指数K线 + 资金费率历史），可重复运行做增量更新
python -m jsq fetch --start 2023-01-01
#    --source vision：用币安历史数据站（按月 zip，不受地区限制，数据截至上个完整月）
#    默认 auto：连得上币安 API 就用 API，否则自动改用历史数据站

# 3. 回测所有策略 × 标的，生成报告 results/<时间>/report.html
python -m jsq backtest

#    也可以 2+3 一条命令：python -m jsq run
#    只测部分：--symbols BTCUSDT,XAUUSDT --strategies funding_fade,ema_cross
#    只做因子分析：python -m jsq analyze

# 4. 用回测选出的参数看当前多空信号
python -m jsq signal
```

`python -m jsq list` 列出全部策略，`python -m jsq <命令> -h` 查看参数。

## 报告内容

| 部分 | 说明 |
|---|---|
| 结论摘要 | 自动列出样本外稳健的“策略×标的”组合，以及显著的预测因子 |
| 因子预测力 | 15 个因子 × 标的，未来 1/4/12/24/72 小时的 Spearman IC、t 值、高/低分组的上涨概率 |
| 策略 × 标的矩阵 | 样本外 夏普 / 胜率 / 总收益 / 回撤 / 交易数 / 平均持仓时长 |
| 样本外排行 | 含盈亏比、多空分别胜率、资金费损益、各时间段是否盈利、净值曲线 |
| 实盘参数 | 用全部历史选出的参数，`signal` 命令使用 |

结果目录里还有 `oos_summary.csv`、`full_grid.csv`（每组参数的全样本表现）、`ic.csv`、`folds.csv`，可以用 Excel 自己筛。

## 策略

| 类别 | 策略 | 思路 |
|---|---|---|
| 资金费率 | `funding_fade` | 费率 z 分数极端时反向（多头拥挤做空） |
| | `funding_follow` | 与上面相反，跟随拥挤方向（对照组） |
| | `funding_level` | 年化费率绝对值过高做空 / 为负做多 |
| | `premium_fade` | 合约相对现货指数的溢价（资金费率的来源，每小时更新）极端时反向 |
| K线 | `ema_cross` `tsmom` `macd_trend` `donchian` | 趋势 / 动量 / 突破 |
| | `rsi_revert` `bb_revert` | 超买超卖均值回归 |
| | `taker_flow` | 主动买入占比异常 → 跟随 |
| 组合 | `trend_funding` | 顺趋势，但费率拥挤时不追 |
| | `breakout_funding` | 突破时资金费率不拥挤才进场 |

出场方式（作为参数一起优化）：仅信号、3ATR 止损、3ATR 止损+6ATR 止盈、4ATR 移动止损、止损+最长 24h、止损+最长 72h。

新增策略：在 `jsq/strategies.py` 写一个返回 1/-1/0 数组的函数，加进 `STRATEGIES` 即可，`tests/test_core.py` 会自动检查它有没有用到未来数据。

## 回测假设（重要）

- K 线收盘出信号，**下一根开盘成交**；每笔扣双边手续费 0.05% + 滑点 0.02%（`--fee`、`--slippage` 可调）
- 持仓跨过资金费结算时刻时，按**真实历史资金费率**收付（多头付正费率）
- 同一根 K 线同时碰到止损和止盈按止损算；跳空穿过止损按开盘价成交
- 1 倍杠杆、复利；加杠杆的收益和回撤近似同比例放大，另有爆仓风险
- **滚动样本外**：首段 40% 数据只用来选参数，后面 60% 分 4 段，每段开始前只用此前的数据挑参数，再拿去跑这一段。报告里的指标都是样本外的拼接结果
- `AUTO` 行 = 每段在所有策略里挑训练期最好的那个，最接近“我回测完就选最好的去做”的真实效果

## 解读建议

- 测几百个组合，总有几个碰巧好看。演示用的纯随机游走数据（SYNNOISE）里，RSI 反转都能拿到样本外夏普 0.7，这就是运气能做到的程度。真正可信的结果应当：交易数多（≥50）、t 值 > 2、多数时间段盈利，并且在相似标的上（比如 XAU 和 PAXG）同样有效
- 币安的黄金/白银/原油/美股合约上线时间短，样本小，结论比 BTC 弱得多。黄金可以用历史更长的 `PAXGUSDT` 做参照
- 美股合约在美股休市时段（夜盘、周末）的价格和资金费率行为与交易时段不同
- 仅供研究，不构成投资建议
